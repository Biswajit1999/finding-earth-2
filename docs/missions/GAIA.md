# Gaia mission view

**Status as of 2026-09-12:** Gaia DR3 public; Gaia DR4 not public in this snapshot.

**Scientific role:** Astrometry, distances, stellar context, multiplicity, and future orbital solutions.

This page is one independent observatory view. Its rows are not converted into a shared mission ranking.

## What it measures

- positions, parallaxes, proper motions, photometry, and selected radial velocities
- astrometric quality and non-single-star indicators
- release-specific astrophysical and variability products

## What it cannot establish

- unreleased Gaia DR4 quantities
- planet atmosphere composition
- habitability from astrometry or multiplicity alone

## Wavelength domain

- broad optical G, BP, and RP photometry; RVS spectroscopy for supported sources

## Resolution concept

- mission scanning astrometry and release-specific spectrophotometric/RVS products

## Data available to this project

- exact-source Gaia DR3 crossmatch for confirmed-planet hosts
- versioned DR4 schema contract with ingestion disabled until public release

## Evidence snapshot

- **OBSERVED — dr3_exact_host_crossmatch**: 4,408 Gaia DR3 source rows. Exact source identifiers from confirmed-planet hosts.
- **FORECAST — dr4_science_rows**: 0 Gaia DR4 rows in project. DR4 is not public in this dated snapshot and is not fabricated.

## Observation / forecast boundary

Only DR3 rows are observations here. DR4 expectations describe a future release and cannot populate observed fields until an official public archive release is verified.

## Official sources

- [Gaia Data Release 3 contents summary](https://www.cosmos.esa.int/web/gaia/dr3) — Gaia DR3 was publicly released on 13 June 2022 with astrometry, photometry, radial velocities, astrophysical parameters, variability, and non-single-star products.
- [Gaia Data Release 4](https://www.cosmos.esa.int/web/gaia/data-release-4) — The official DR4 page still describes the release as forthcoming; no DR4 rows are ingested.
